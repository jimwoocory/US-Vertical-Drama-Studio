# V10 Roadmap

## Gate 0 — Architecture audit

Map V9 ownership, contracts, controller gates, build paths, distributions and tests. Define a US-focused V10 writing workflow, one authoritative Story Truth, human approval evidence, Story Change Request invalidation, and preservation of bilingual and `inner_voice` behavior.

## Gate 1 — Core isolation and contracts

Create a V10-only canonical Core/manifest and machine-readable artifact contracts. Keep every V9 source and generated surface unchanged. Demonstrate whether DSH can enforce version-bound human approval and downstream invalidation at runtime.

## Gate 2 — Story and episode architecture

Implement only the approved minimum skills for Intake/Adaptation, Story Architecture and Episode Architecture. Validate structural invariants deterministically and route semantic judgments through explicit review evidence.

## Gate 3 — Script and canon workflow

Connect approved Story Packages to Screenwriter, independent Script Doctor review, and a derived continuity/state ledger. Add Story Change Request and stale-artifact behavior.

## Gate 4 — Existing director pipeline compatibility

Reuse or generate the needed V9 downstream skills under V10 ownership without changing V9. Preserve Storyboard, Performance/Cinematography, model adapter, QA, bilingual requests, inner monologue/voiceover fields, and V9 Golden Cases as downstream regression fixtures.

## Gate 5 — DSH validation and documentation

Verify the DSH skill catalog and complete test suite with V9 regressions. Packaging, workbench UI, push, and publishing require a separate explicit task.
