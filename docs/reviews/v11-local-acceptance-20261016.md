## 英语 TTS 超时反例

以《她冒充了我》第一集六场剧情的**人工结构化改述排练材料**为输入，规划器先输出 `113.9s`。使用 Windows 内置 `Microsoft Zira Desktop`、英语 `en-US`、默认语速合成所选 8 条对白/旁白，读取输出 WAV PCM 数据段计算各句语音时长。

采用**保守的演出换算**：把每条测得的语音秒数相对规划器同条 `speech_budget_seconds` 的偏差累计到原 113.9 秒预算，得出 `125.52s`，高于上限 `120s`，超出约 `5.52s`。

这个数值是保守代理测算，不是完整声画合成或真人表演实测，且未把并行动作可吸收的所有松弛时间精确重算；不能把它表述为最终实际成片时长。无论如何，原计划不满足足够的安全余量，需由导演重新校正对白节奏、动作和场景预算，而不是提高语速来蒙混过关。

观测的重点问题包括 `DU-003`、`DU-007`、`DU-009` 对白读音时间明显高于估算。部分源单元也有节余，应在真正完成时间轴重排前做精确并行/串行重算，避免机械把偏差都累计成真实时长。

证据位于公司电脑临时工作目录：
`%TEMP%/v11-local-tts-evidence-20261016.json`，对应 WAV 文件在 `%TEMP%/v11-acceptance-wav-20261016/`。属于本地验收副产物，不代表产品交付音频。
