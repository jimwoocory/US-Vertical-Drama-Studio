# Visual Asset Ledger Template

## Character

`CHAR-01` — English name; age/presentation; face and hair anchors; body/silhouette; recurring identity markers; approved reference image if supplied.

## Costume / look

`LOOK-01A` — linked character ID; garment layers; palette/material; footwear; accessories; condition; episode/scene range; transition trigger.

## Scene / set

`SET-01` — place and geography; time/weather/light; key set dressing; visual anchors; screen-direction constraints; episode/scene range.

## Hero prop

`PROP-01` — form/material/scale; condition; owner or holder; current location; narrative function; state changes; episode/scene range.

## Shot linkage

`SHOT-01` — source scene; range; `CHAR-*`; `LOOK-*`; `SET-*`; `PROP-*`; prompt ID; continuity notes.
