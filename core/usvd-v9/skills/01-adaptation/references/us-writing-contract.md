# US Writing Contract

这是一份跨 USVD 01 与 USVD 02 传递的项目合同。它约束创作选择和验收证据，不取代 Adaptation Brief、Story Bible、Beat Sheet 的既有 Gate，也不等同于市场验证。

## 最小合同

| 字段 | 填写方式 |
| --- | --- |
| 项目 / 市场 / 形式 | 项目名；目标市场（默认美国）；竖屏短剧或漫剧。 |
| 平台 / 发行面 | 已定的平台、渠道或“未定发行面”；不要把竞品观察写成平台批准。 |
| 目标观看动机 / 假设 | 如“情绪逃离、关系抉择、复仇回报”；说明是 `EVIDENCED`、`ASSUMED` 或 `UNVERIFIED`，而非无证据的人口刻板印象。 |
| 类型 / 情绪结局 | 类型承诺，以及季终或故事结局希望观众带走的情绪。 |
| 季 / 集长度 | 计划集数、篇章（如有）和预计单集长度；未知可标状态。 |
| 变现模式 | 免费、广告、订阅、币或组合；只记录发行约束，不推导固定反转秒数或付费集数。 |
| 原创 / 改编与来源 | 标明原创或改编；改编写来源素材和适配边界，原创写原创来源。 |
| 交付范围 | `writing-only` 或 `full-production`；记录交给 controller 及 USVD 03/04 的输入范围，不扩大 USVD 01/02 的写作边界。 |
| 证据日期 / 假设 | 每项外部依据写日期和来源；没有依据写明假设及待验证方式。 |
| 交付语言 | 可为“中文制作说明 + 英文对白交付”；不得因此改变后续技能边界。 |

`ASSUMED` 表示为继续工作而暂定的可调整参数；`UNVERIFIED` 表示尚未核验的声明或缺失输入。两者不能写成研究证实、受众事实或商业结果。除非该缺口会改变当前 Gate 的核心 Canon 或改编因果，否则记录缺口后继续工作。

用户明确指定的市场、形式、集数、时长、交付范围等标 `BRIEF CONFIRMED`（来源：当前 brief），不能误标成模型自行暂定的 `ASSUMED`。这表示创作约束已指定，不表示它的市场效果已验证。`EVIDENCED` 外部受众结论仍须可核查来源、日期与适用范围。

## 跨集承诺与状态证据

Story Bible 和 Beat Sheet 共同使用下列最小记录。沿用项目已有 `SCxx` / `EPxx` 等引用，不强制新编号。

| 记录 | 必须说明 |
| --- | --- |
| Promise Ledger | `Promise ID`、来源（广告/标题/故事）及批准状态、承诺内容、批准的兑现 window、状态。Story Bible 的正片落点仅为 `PLANNED`，不得称已兑现；只有已批准的既有来源可形成承诺，新广告/标题标 `PROPOSED` 直至批准。延期要写理由与替代兑现；原 window 不可自行改动，改动标 `REQUIRES APPROVAL`。 |
| State Change | EP/篇章、主角目标、主动行动、具体代价、信息/权力/关系变化、关联 Promise ID。篇章及季终复核到期和未兑现项。 |
| 关系差异 | 主要角色/关系分别采用的策略、价值冲突或结果；防止只交换反派、受辱者或救场者而重复同一模式。 |

悬念可以提出下一集问题，但每集仍须有本集可见的局部 payoff 和状态推进；悬念不是 payoff 的替代品。季终可写 `NONE / FINALE`，但须以终局情绪目的地和 `Series Question` 兑现替代；非季终仍须给出具体的下一集问题。

## 紧凑示例

**好：**`P-07` 来源“标题：她会公开真相”；故事证据 `EP03 SC04`，window `EP04–EP05`。EP04 主角拒绝封口费（行动），失去工作（代价），掌握的录音从私密变为公开风险（状态变化）；若移至 EP06，保留原 window，记录原因、EP05 的部分公开视频（替代兑现），并标 `REQUIRES APPROVAL`。

**坏：**标题承诺“今晚揭穿他”，正片只让主角再被羞辱一次并以“真相快到了”结尾；账本改成 `EP06–EP08`，却没有理由、替代兑现或批准记录。
